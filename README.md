
【2月8日】中午在狮子湖吃完午饭去李彦锦家，下午两点从李彦锦家出发，晚上到西昌，在邛海
旁边吃烧烤和小猪儿肉，然后在青庐宾馆睡觉。

【2月9日】早上在青庐宾馆附近的早餐店吃油条和豆浆，上午在西昌邛海沿着海边走，然后坐船。
中午吃羊肉，吃完去看了建昌古城。下午看了黄联土林。晚上开车到攀枝花，去宋艳华餐厅吃晚饭。
最后去川惠大酒店睡觉。

【2月10日】早上从川惠大酒店起床，在附近吃了一碗面，然后去参观了攀枝花的三线（历史类）建设
博物馆，然后中午吃的二两羊肉米线，然后坐车前往云南丽江，下午到了丽江后，逛了丽江古城，晚上
吃的丽江古城里的一个菌子汤锅，然后回到漫格拉酒店睡觉。

【2月11日】早上从漫格拉酒店起床，然后吃了酒店提供的免费的早餐，还是自助早餐，味道也十分
不错。吃完早餐后就乘车前往了云南大理。到了大理之后，我们参观了抗日将军周保中的故居。然后
中午吃了店名叫傣家姑娘的饭店提供的具有当地民族特色的午饭。然后我们就去了八部天龙影视城玩，
和里面的NPC进行了互动。玩玩后我们回酒店放了东西，就去逛大理古城。我们先吃了一些小吃，其
中令我印象最深的是乳扇，然后晚上的主食是云南的过桥米线。最后我们回到上善若水酒店睡觉。

【2月12日】上善若水酒店是一个具有古代白族风格的现代建筑，早上从这个酒店起来后就先找了
一家早餐店，品尝了一下酥油茶，我还吃了两个猪肉包子。然后我们去洱海边上玩，我和李彦锦在
洱海边上骑了一会儿共享单车，我还拍了很多照片。然后我还在洱海岸边捡了一些十分扁平的石头
来打水漂。接着我们又去了大理古城，去看一下有没有什么好吃的。古城里面有很多免费试吃的零食
，好吃是好吃，但是香精味太重了，我不是很喜欢，结果到了最后也没有找到我想吃的小吃。于是
我就在路边随便找了一家面馆吃了一碗猪肉挂面，就当吃中午饭了。然后我们就开车从云南大理，
到云南西双版纳。总路程大约600km，从中午一直开到了晚上十点。沿途我们还买了一些水果，甘蔗，
花生之类的，还有芭蕉，和香蕉差不多。然后我们晚饭吃的是兰州牛肉拉面。最后我们到悦鸿假日酒店过夜。

【2月13日】我们早上从悦鸿假日酒店起床，然后我吃了一笼烧卖，也就是五个烧卖。吃完后我们
前往了西双版纳的植物园，看了非常多的植物，还感受了热带雨林的氛围，虽然是人造的。中午
在植物园吃的方便面，然后下午到傣族园去看了泼水活动，去傣族园的途中还买了很多好吃的水果。
晚上我们吃的是菠萝饭，然后还逛了星光夜市，十分的热闹。最后我们回悦鸿酒店睡觉了。


【2月14日】早上我们从悦鸿酒店起床，说的是七点半起来，但是我们赖床赖到了七点四十
然后我们在酒店旁边的兰州拉面面馆吃了早饭。我吃的是鸡蛋拉面，味道很不错，就是面汤
太咸了。然后我们出发去了野象谷，那里有很多大象，还有植物，花，还看了很多蝴蝶。然后我们中午
在傣家乐餐厅吃了午饭，傣家乐餐厅是一个农家乐，那里的乌骨鸡的味道很不错。吃完之后我们
又开车，一直开开开，开到了晚上八点。我们晚上住的是欧寓客栈。我们把行李放到宾馆后
就去了附近的渡官古镇去找一些小吃来吃，来充当我们的晚饭。最后我吃的是锅边土豆，李彦锦
是狼牙土豆。吃完后李彦锦海请我喝了蜜雪冰城奶茶，味道很不错。最后我们回酒店睡觉了。
